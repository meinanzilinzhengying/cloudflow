## 1. 快速入门

### 1.1 登录系统

1. 打开浏览器，访问 CloudFlow 平台地址：`http://<center-ip>:8080`
2. 输入用户名和密码
3. 点击「登录」按钮

### 1.2 主界面概览

登录后您将看到主仪表盘，包含：

| 区域 | 功能描述 |
|------|----------|
| 顶部导航栏 | 系统菜单、搜索框、用户信息 |
| 左侧菜单栏 | 功能模块导航 |
| 主内容区 | 当前选中模块的内容展示 |
| 底部状态栏 | 系统状态、当前时间 |

### 1.3 首次使用流程

```
登录系统
   │
   ▼
查看仪表盘（默认展示）
   │
   ▼
配置筛选条件
   │
   ▼
查看流量数据
   │
   ▼
导出报告或创建自定义仪表盘
```

## 2. 流量监控

### 2.1 实时流量视图

进入「流量监控」模块，您可以看到：

- **实时流量趋势图**：展示最近 5 分钟的流量变化
- **协议分布饼图**：显示各协议占比
- **Top 10 流量来源**：列出流量最大的前 10 个来源 IP
- **Top 10 流量目标**：列出流量最大的前 10 个目标 IP
- **实时告警列表**：显示当前活跃的告警

### 2.2 流量详情

点击流量趋势图中的数据点，可以查看该时间点的详细流量信息：

- 时间戳
- 源 IP / 端口
- 目的 IP / 端口
- 协议类型
- 字节数
- 数据包数
- K8s 资源信息（Namespace、Service、Pod）

## 3. 多维度筛选

### 3.1 筛选条件

CloudFlow 支持以下筛选维度：

| 筛选维度 | 说明 | 示例值 |
|----------|------|--------|
| **时间范围** | 支持相对时间和绝对时间 | 最近 1小时、今日、自定义时间 |
| **K8s Namespace** | Kubernetes 命名空间 | default、kube-system、prod |
| **K8s Service** | Kubernetes 服务名称 | frontend、api-gateway |
| **K8s Pod** | Kubernetes Pod 名称 | frontend-7f9d98c6d9-2xqkd |
| **协议类型** | 网络协议 | TCP、UDP、HTTP、HTTPS、DNS、ICMP |
| **源 IP** | 来源 IP 地址 | 192.168.1.100 |
| **目的 IP** | 目标 IP 地址 | 10.0.0.50 |

### 3.2 使用筛选器

1. 在「流量监控」或「高级查询」页面找到筛选区域
2. 选择筛选条件类型
3. 输入或选择筛选值
4. 点击「应用筛选」按钮

### 3.3 高级查询

进入「高级查询」页面，可以使用更复杂的筛选逻辑：

```json
// 示例查询条件
{
  "start_time": "2024-01-15 08:00:00",
  "end_time": "2024-01-15 18:00:00",
  "filters": [
    {
      "field": "protocol",
      "operator": "in",
      "value": ["HTTP", "HTTPS"]
    },
    {
      "field": "k8s_namespace",
      "operator": "equals",
      "value": "prod"
    },
    {
      "field": "bytes",
      "operator": "greater_than",
      "value": 1024000
    }
  ],
  "sort_by": "bytes",
  "sort_order": "desc",
  "page": 1,
  "page_size": 50
}
```

## 4. 数据导出

### 4.1 导出格式

CloudFlow 支持两种导出格式：

| 格式 | 说明 | 适用场景 |
|------|------|----------|
| **JSON** | 结构化数据格式 | 数据集成、API 对接 |
| **CSV** | 表格数据格式 | Excel 分析、报表制作 |

### 4.2 导出步骤

1. 设置筛选条件（可选）
2. 点击页面右上角的「导出」按钮
3. 选择导出格式（JSON 或 CSV）
4. 等待文件生成并下载

### 4.3 导出内容

导出文件包含以下字段：

| 字段名 | 说明 |
|--------|------|
| `timestamp` | 时间戳（ISO 8601 格式） |
| `src_ip` | 源 IP 地址 |
| `src_port` | 源端口 |
| `dst_ip` | 目的 IP 地址 |
| `dst_port` | 目的端口 |
| `protocol` | 协议类型 |
| `bytes` | 字节数 |
| `packets` | 数据包数 |
| `duration_ms` | 持续时间（毫秒） |
| `k8s_namespace` | K8s 命名空间 |
| `k8s_service` | K8s 服务名 |
| `k8s_pod` | K8s Pod 名 |
| `flow_type` | 流量类型（入站/出站） |

## 5. 自定义仪表盘

### 5.1 创建仪表盘

1. 进入「仪表盘」模块
2. 点击「新建仪表盘」按钮
3. 填写基本信息：
   - **名称**：仪表盘显示名称
   - **描述**：仪表盘用途说明
   - **布局**：网格布局或自由布局
   - **刷新频率**：自动刷新间隔（10秒/30秒/1分钟/5分钟）
4. 点击「创建」按钮

### 5.2 添加组件

1. 进入仪表盘编辑模式
2. 点击「添加组件」按钮
3. 选择组件类型：
   - **图表组件**：折线图、柱状图、饼图
   - **表格组件**：数据表格
   - **仪表盘组件**：圆形仪表盘
   - **文本组件**：标题、说明文字
4. 配置组件参数：
   - 数据源选择
   - 显示字段
   - 样式设置
5. 点击「确认添加」

### 5.3 组件类型说明

| 组件类型 | 功能描述 | 适用场景 |
|----------|----------|----------|
| **折线图** | 展示数据随时间变化趋势 | 流量趋势、指标变化 |
| **柱状图** | 展示分类数据对比 | 协议分布、服务对比 |
| **饼图** | 展示占比关系 | 流量来源分布 |
| **表格** | 展示详细数据列表 | Top N 流量、告警列表 |
| **仪表盘** | 展示单一指标的当前值 | CPU 使用率、内存使用率 |
| **文本** | 展示标题或说明 | 仪表盘标题、注释说明 |

### 5.4 管理仪表盘

- **编辑**：修改仪表盘配置和组件
- **复制**：创建仪表盘副本
- **分享**：生成分享链接
- **删除**：删除仪表盘（需确认）

## 6. 大屏展示

### 6.1 进入大屏模式

1. 进入「大屏展示」模块
2. 选择要展示的仪表盘
3. 点击「全屏展示」按钮

### 6.2 大屏组件

大屏模式包含以下默认组件：

| 组件 | 说明 | 位置 |
|------|------|------|
| **流量趋势** | 实时流量折线图 | 顶部左侧 |
| **协议分布** | 协议占比饼图 | 顶部右侧 |
| **CPU 使用率** | 系统 CPU 使用率 | 中部左侧 |
| **内存使用率** | 系统内存使用率 | 中部右侧 |
| **实时告警** | 当前告警列表 | 底部 |

### 6.3 大屏控制

- **自动刷新**：大屏模式下自动刷新数据
- **切换仪表盘**：通过下拉菜单切换不同仪表盘
- **退出全屏**：按 ESC 键或点击退出按钮

## 7. 告警管理

### 7.1 查看告警

进入「告警管理」模块，可以看到：

- **活跃告警**：当前触发的告警
- **历史告警**：已解决的告警记录
- **告警统计**：告警数量趋势

### 7.2 告警级别

| 级别 | 标识 | 含义 |
|------|------|------|
| **Critical** | 红色 | 严重告警，需要立即处理 |
| **Warning** | 黄色 | 警告告警，需要关注 |
| **Info** | 蓝色 | 信息告警，仅供参考 |

### 7.3 告警处理

- **确认告警**：标记告警已被关注
- **解决告警**：标记告警已处理完成
- **添加备注**：记录处理过程和结果
- **设置规则**：配置告警触发条件和通知方式

### 7.4 告警规则配置

```yaml
# 示例告警规则
rule:
  name: "HighTrafficAlert"
  description: "流量超过阈值告警"
  condition: "bytes_per_second > 10000000"
  threshold: 10000000
  severity: "critical"
  notification_channels:
    - email
    - webhook
  enabled: true
```

## 8. 用户管理

### 8.1 用户角色

| 角色 | 权限 | 说明 |
|------|------|------|
| **管理员** | 全部权限 | 可管理系统设置、用户、配置 |
| **运维人员** | 读写权限 | 可查看数据、创建仪表盘、导出数据 |
| **普通用户** | 只读权限 | 可查看数据，不可修改配置 |

### 8.2 登录与登出

- **登录**：输入用户名密码验证身份
- **登出**：点击右上角用户头像 → 选择「退出登录」
- **密码修改**：点击右上角用户头像 → 选择「修改密码」

### 8.3 会话管理

- 登录会话有效期为 24 小时
- 长时间无操作自动登出
- 支持多端同时登录

## 9. 最佳实践

### 9.1 数据查询优化

1. **合理设置时间范围**：避免查询过长时间范围导致性能下降
2. **使用筛选条件**：通过多维度筛选减少返回数据量
3. **利用分页功能**：查询大量数据时使用分页

### 9.2 仪表盘设计

1. **布局合理**：将相关组件放在一起
2. **刷新频率**：根据数据更新频率设置合适的刷新间隔
3. **组件数量**：单个仪表盘不宜过多组件（建议不超过 10 个）

### 9.3 告警配置

1. **设置合理阈值**：避免过于敏感导致告警泛滥
2. **配置通知渠道**：确保告警能及时通知到相关人员
3. **定期审查规则**：根据实际情况调整告警规则

### 9.4 性能优化

| 优化项 | 建议 |
|--------|------|
| 数据保留 | 根据业务需求设置合理的保留期限 |
| 索引优化 | 对常用查询字段创建索引 |
| 资源配置 | 根据流量规模调整组件资源限制 |
